# 校园班级管理分
***
适用于校园班级（整体）周流动分管理网站  
>[!Warning]
>该项目使用deepseek制作，可能会有很多BUG。  
***
## 一、部署与使用说明  
1. 环境要求：PHP 7.4+，MySQL 8.0+，启用 PDO。    
2. 将文件下载并上传至服务器  
3. 访问服务器地址，并根据引导填写数据库配置、管理员账号、和密保问题  
>[!Warning]
>注册后第一位用户权限默认为最高权限，无法删除（系统管理员），请注意保存账号密码！！！
>若未设置密保问题，则可能会导致数据丢失。
>密保问题**暂时**无法自定义  
***
## 核心功能覆盖清单  
- [x] 小数点计分  
- [x] 快捷扣分/加分（预设奖惩类型，可临时调分）  
- [x] 学期/周/月管理（自动根据学期开始日期计算周次、月次，可手动切换学期）  
- [x] 按班级排名（周榜、月榜、学期榜，分年级展示）  
- [x] 角色权限（超级管理员、积分管理员、系统管理员，数据隔离）  
- [x] 移动端适配（响应式布局，触摸友好）  
- [x] 数据备份与恢复（导出SQL文件，上传恢复）  
- [x] 操作日志（记录管理员关键操作及IP）  
- [x] 密码强度与锁定（前端提示 + 后端验证，5次失败锁1分钟）  
- [x] 班级负责人记录（class_leader 字段）  
- [x] 冻结班级（阻止积分操作，排行榜显示冻结标记）  
- [x] 自定义奖惩类型（管理员可添加）  
- [x] 上传图片  
- [x] 增加/删除班级（可批量使用csv模板导入）  
- [x] 访客查看  
- [x] 支持导出积分记录   
- [x] 二次验证
- [x] 支持查看服务器状态
- [x] 支持旧版本升级
